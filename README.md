# Tuchín Turismo

Plataforma web orientada a promover el turismo cultural y visibilizar la riqueza histórica, artesanal y natural de Tuchín, Córdoba, reconocido como la cuna del sombrero vueltiao y territorio de la cultura Zenú.

El proyecto busca utilizar la tecnología como un medio para conectar a los visitantes con experiencias culturales auténticas, promover la artesanía local y contribuir a la visibilidad y desarrollo económico de las comunidades de la región.

---

# Descripción

Tuchín, ubicado en el departamento de Córdoba, Colombia, posee un importante patrimonio cultural y artesanal relacionado principalmente con la comunidad indígena Zenú y la elaboración del sombrero vueltiao.

A pesar de esta riqueza cultural, existe una limitada presencia digital que permita mostrar al mundo los atractivos, productos artesanales y experiencias disponibles en el municipio.

Tuchín Turismo surge como una propuesta tecnológica para crear un espacio digital donde los visitantes puedan conocer la cultura, planificar sus visitas y descubrir experiencias auténticas.

La plataforma también incorpora un panel administrativo que permite gestionar el contenido del sitio sin necesidad de modificar directamente el código fuente.

El proyecto busca establecer un puente entre la tradición y la tecnología, utilizando herramientas digitales para contribuir a la promoción del turismo cultural y al fortalecimiento de las comunidades locales.

---

# Objetivo

Desarrollar un sitio web interactivo y accesible que promueva el turismo cultural en Tuchín, destacando su identidad Zenú y su patrimonio artesanal, con el propósito de posicionarlo como un destino turístico sostenible en Colombia.


- Crear un sitio web responsivo con un diseño moderno que muestre los principales atractivos turísticos de Tuchín.
- Implementar componentes de información turística relacionados con cultura, experiencias, alojamiento y transporte.
- Desarrollar secciones especializadas para promover la artesanía local, especialmente el sombrero vueltiao.
- Incorporar herramientas digitales para facilitar la planificación de visitas.
- Implementar mapas interactivos y calendarios de eventos.
- Proporcionar información de contacto para visitantes.
- Desarrollar un panel administrativo para gestionar y actualizar el contenido multimedia.
- Facilitar la administración de experiencias, eventos, productos artesanales y galerías.


# Público objetivo

La plataforma está dirigida principalmente a personas interesadas en conocer la cultura y el patrimonio de Tuchín y del territorio Zenú.

Entre los principales segmentos se encuentran:

- Turistas nacionales e internacionales.
- Viajeros interesados en turismo cultural.
- Personas interesadas en experiencias comunitarias.
- Estudiantes.
- Investigadores.
- Agencias de viajes sostenibles.
- Personas interesadas en artesanías colombianas.
- Visitantes interesados en conocer la cultura Zenú.
- Personas interesadas en experiencias gastronómicas y ecológicas.

La plataforma busca generar valor tanto para los visitantes como para las comunidades locales.

Para los visitantes, proporciona acceso a información y experiencias culturales.

Para las comunidades, permite aumentar la visibilidad de sus productos, actividades y patrimonio cultural.

# Características principales

## Sitio web público

La plataforma cuenta con diferentes secciones orientadas a proporcionar información turística y cultural.

### Inicio

Página principal de la plataforma.

Incluye:

- Presentación visual de Tuchín.
- Imágenes representativas.
- Información introductoria.
- Botones de navegación hacia las principales secciones.

### Artesanías

Sección dedicada a la promoción de productos artesanales.

Incluye:

- Tiendas de productos artesanales.
- Carrusel de productos.
- Información de los productos.
- Información de las tiendas.
- Opción de contacto y compra mediante WhatsApp.

Esta sección busca brindar mayor visibilidad a los artesanos y facilitar el contacto con posibles compradores.

### Cultura

Sección enfocada en la identidad cultural de Tuchín y el pueblo Zenú.

Incluye información relacionada con:

- Historia de Tuchín.
- Cultura Zenú.
- Historia y significado del sombrero vueltiao.
- Información demográfica.
- Patrimonio cultural.
- Tradiciones locales.

### Experiencias

Sección destinada a mostrar actividades y experiencias disponibles para los visitantes.

Entre ellas se contemplan:

- Tours culturales.
- Talleres de tejeduría.
- Senderismo ecológico.
- Gastronomía local.
- Experiencias relacionadas con la cultura Zenú.

### Visítanos

Sección con información práctica para ayudar al visitante a planificar su viaje.

Incluye:

- Información de transporte.
- Alojamiento.
- Clima.
- Mapas interactivos.
- Información útil para los visitantes.

### Eventos

Calendario destinado a mostrar actividades y festividades de la región.

Entre los eventos contemplados se encuentran:

- Festival del Sombrero Vueltiao.
- Encuentros ancestrales.
- Festividades culturales.
- Actividades comunitarias.

### Testimonios

Sección destinada a mostrar las experiencias de los visitantes.

Incluye:

- Comentarios de turistas.
- Formulario para registrar experiencias.
- Opiniones sobre las actividades realizadas.

### Contacto

Sección destinada a facilitar la comunicación con la plataforma y entidades relacionadas.

Incluye:

- Formulario de contacto.
- WhatsApp.
- Redes sociales.
- Información de la alcaldía local.
- Información de contacto general.

### Footer

El pie de página permite acceder rápidamente a diferentes recursos de la plataforma.

Incluye enlaces y accesos relacionados con:

- Turismo.
- Cultura.
- Experiencias.
- Contacto.
- Información útil.

# Panel administrativo

El proyecto incorpora un dashboard administrativo que permite gestionar el contenido del sitio web.

El objetivo del panel es permitir que los administradores actualicen la información sin necesidad de modificar directamente el código fuente.

## Login

El sistema cuenta con una sección de autenticación para acceder al panel administrativo.

Incluye:

- Usuario.
- Contraseña.
- Validación mediante reCAPTCHA.

## Inicio

Permite administrar la imagen principal utilizada en la sección de inicio.

Funcionalidades:

- Seleccionar una imagen.
- Cargar la imagen.
- Actualizar el contenido visual.

## Cultura

Permite administrar las imágenes utilizadas en la sección cultural.

Funcionalidades:

- Cargar imágenes.
- Guardar imágenes.
- Actualizar contenido multimedia.

## Experiencias

Permite administrar las tarjetas de experiencias disponibles.

Cada experiencia puede contener:

- Título.
- Imagen.
- Fecha.
- Descripción.

También permite:

- Agregar experiencias.
- Eliminar experiencias.

## Eventos

Permite administrar los eventos mostrados en el sitio.

Cada evento contiene:

- Icono.
- Título.
- Descripción.

También permite:

- Agregar eventos.
- Eliminar eventos.

## Productos

Permite administrar los productos artesanales disponibles.

Cada producto puede contener:

- Nombre.
- Descripción.
- Precio.
- Tienda.
- Fotografía.

También permite:

- Agregar productos.
- Eliminar productos.

## Contacto

Permite administrar los números de contacto utilizados por la plataforma.

Se pueden configurar números relacionados con:

- Ventas.
- Asesoría.
- Ayuda.

## Galería

Permite administrar el contenido multimedia de la plataforma.

Incluye funcionalidades para:

- Mostrar la lista de contenido.
- Agregar nuevo contenido multimedia.
- Seleccionar contenido principal.
- Seleccionar contenido secundario.
- Eliminar contenido almacenado.

# Configuración del Frontend

Ingresar a la carpeta del frontend:

```bash
cd frontend
```

Instalar las dependencias:

```bash
npm install
```

Ejecutar el proyecto:

```bash
npm start
```

La aplicación estará disponible normalmente en:

```text
http://localhost:3000
```

---

# Configuración del Backend

Ingresar a la carpeta:

```bash
cd backend
```

Instalar las dependencias:

```bash
npm install
```

Configurar la conexión a MySQL utilizando las variables de configuración correspondientes.

Después ejecutar el backend mediante el archivo principal:

```bash
node app.js
```

El puerto utilizado dependerá de la configuración definida en el backend.

---

# Base de datos

Para configurar la base de datos:

1. Instalar MySQL.
2. Crear una base de datos para el proyecto.
3. Ejecutar los archivos SQL ubicados dentro de `backend/`.
4. Configurar las credenciales de conexión.
5. Iniciar el backend.
6. Ejecutar el frontend.

Es importante configurar correctamente:

- Host de MySQL.
- Puerto.
- Usuario.
- Contraseña.
- Nombre de la base de datos.

El proyecto busca contribuir a la promoción digital de Tuchín y su patrimonio cultural.

# Conclusión

Tuchín Turismo representa una propuesta tecnológica orientada a utilizar el desarrollo web como herramienta para promover el patrimonio cultural y turístico de Tuchín.

La plataforma combina una interfaz moderna desarrollada con React con un backend basado en Node.js, Express y MySQL, permitiendo administrar dinámicamente la información presentada a los visitantes.

El sistema busca conectar a los turistas con la cultura Zenú, las experiencias locales y los productos artesanales, mientras proporciona a los administradores herramientas para mantener actualizado el contenido de la plataforma.

De esta manera, el proyecto plantea un punto de encuentro entre tecnología, turismo, cultura y desarrollo económico local.
